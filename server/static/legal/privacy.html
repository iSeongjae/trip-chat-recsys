개인정보 처리방침

이제 뭐 하지?
개인정보 처리방침 시행일: 2026년 ○월 ○일

“이제 뭐 하지?”(이하 “서비스”)는 이용자의 개인정보를 소중히 다루며, 추천에 꼭 필요한 정보만 최소한으로 처리합니다.

1. 처리하는 개인정보와 목적

로그인 근거: 서비스 이용 계약

항목: Google 로그인 식별자(계정 고유번호)

목적: 회원 구분, 로그인 유지

서비스 이용 기록 근거: 서비스 이용 계약

항목: 대화 내용, 추천 결과, 누른 장소, 길찾기·검색 클릭, 저장한 장소, 방문 체크

목적: 개인 맞춤 추천, 추천 품질 개선

위치 정보 (선택) 근거: 별도 동의

항목: 추천을 요청한 시점의 현재 위치

목적: 근처 장소 추천, 도보 시간 계산

자동 수집 근거: 정당한 이익

항목: 접속 일시, IP 주소, 브라우저 정보

목적: 부정 이용 방지, 오류 확인

• 이메일, 이름, 프로필 사진은 받지 않습니다.
• 위치 정보는 별도로 동의한 경우에만 사용하며, 동의하지 않아도 지역을 직접 입력해 이용할 수 있습니다.
• 위치 정보는 추천 계산에만 쓰고 정확한 좌표는 저장하지 않습니다. 필요한 경우 동네 단위로만 저장합니다.
• 로그인 없이 이용하는 경우(둘러보기/게스트)에도 서비스 이용 기록과 자동 수집 항목이 같은 목적으로 처리됩니다.

2. 보유 기간과 파기

  • • 회원 정보, 대화 내용, 저장·방문 목록: 탈퇴 시 지체 없이 삭제합니다.
  • • 로그인 없이 이용한 기록: 마지막 이용일로부터 30일 뒤 위와 같이 삭제합니다.
  • • 접속 기록(IP 등): 부정 이용 방지를 위해 서버 접속 로그에 최대 90일 보관 후 삭제하며, 데이터베이스에는 저장하지 않습니다. 다만 IP 로 추정한 접속 국가(예: 한국, 일본)만 이용 기록에 남깁니다.
  • • 추천을 보고 고르거나 넘긴 기록(행동 기록)은 삭제 시점에 계정과의 연결을 끊고 위치를 약 20km 단위로 바꿔 개인을 알아볼 수 없게 한 뒤, 추천 품질 개선과 추천 모델 학습에 계속 이용합니다. 대화 원문은 여기에 포함하지 않습니다.

3. 외부 서비스에 맡기거나 전송하는 정보

OpenAI (API) 국가: 미국

전송: 대화 내용

목적: 대화에서 여행 조건 추출

보유: OpenAI API 데이터 정책에 따름

Google (로그인) 국가: 미국

전송: 로그인 요청

목적: 본인 확인

보유: Google 정책에 따름

Supabase (데이터베이스) 국가: 일본 (도쿄)

맡기는 정보: 계정 식별자, 대화 내용, 추천·이용 기록, 저장 목록

목적: 서비스 데이터 보관

보유: 위 2항의 보유 기간과 같음

Cloudflare (네트워크) 국가: 미국 등

전송: 접속 요청(IP 주소 등)

목적: 암호화 연결(HTTPS) 중계, 보안

보유: Cloudflare 정책에 따름

• 대화 내용은 인터넷을 통해 암호화되어 전송됩니다.
• 대화에 이름, 연락처 같은 개인정보를 적지 않도록 권장합니다.
• 위 목적 외에는 개인정보를 제3자에게 제공하거나 판매하지 않습니다. 광고 목적으로 이용하지 않습니다.

4. 쿠키

로그인 상태를 유지하기 위한 세션 쿠키만 사용합니다. 광고나 추적용 쿠키는 사용하지 않습니다. 브라우저 설정에서 쿠키를 거부할 수 있지만, 이 경우 로그인이 유지되지 않습니다.

5. 만 14세 미만

서비스는 만 14세 이상만 이용할 수 있으며, 만 14세 미만 아동의 개인정보를 알고 수집하지 않습니다.

6. 이용자의 권리

이용자는 언제든지 자신의 정보를 조회·삭제하거나 탈퇴할 수 있습니다.

  • • 저장한 장소, 방문 체크 삭제: 앱의 저장목록에서 바로 삭제
  • • 위치 동의 철회: 설정에서 끄거나 브라우저의 위치 권한을 해제
  • • 전체 삭제: 설정 > 탈퇴 (개인 기록 즉시 삭제, 익명 처리된 행동 기록은 2항에 따라 보관)
  • • 그 밖의 요청: 아래 연락처로 문의

7. 안전성 확보 조치

  • • 모든 통신은 HTTPS로 암호화합니다.
  • • 로그인 식별자는 서비스 내부 ID와 분리해 보관하고, 접근 권한을 운영자로 제한합니다.
  • • 비밀번호를 수집·저장하지 않습니다.
